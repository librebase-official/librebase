# LibreBase Project

LibreBase is an open knowledge base and research platform at `~/Documents/coding-projects/librebase`.

## Architecture

- `admin-api/` — administrative API
- `data-studio-ui/` — data studio web interface
- `kms/` — knowledge management system
- `licontainer/` — license container / compliance
- `apps/` — user-facing applications
- `packages/` — shared packages
- `src/` — core source
- `scripts/` — automation scripts
- `tests/` — test suite
- `deploy/` — deployment configs
- `docs/` — documentation
- `data/` — data directory
- `benchmarks/` — performance benchmarks
- `mcp/` — MCP server integration
- `.venv/` — Python virtual environment

## Key files

- `HANDOFF.md` — project handoff document (primary reference)
- `README.md` — project overview
- `li.toml` — Li configuration
- `pricing-artifact.html`, `pitchdeck-clients.html`, `pitchdeck-sales.html` — business artifacts
- `pricing_validation.py` — pricing validation script
- `librebase_competitive_analysis.json` — competitive landscape data (also at `~/.grok/`)
- `CHANGELOG.md` — version history

## Principles

- Knowledge should be findable, attributable, and freely reusable
- Every fact should have a source; uncertainty should be flagged
- Prefer structured data (JSON, tables) over free-form prose for knowledge base content
- Track competitive intelligence with citations
- License compliance lives in `licontainer/` — always check it when adding new data sources
