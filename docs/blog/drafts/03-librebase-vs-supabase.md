# Librebase vs Supabase: what is different today

**Keyword:** supabase alternative  
**Intent:** commercial

Supabase is a full product with years of surface area. Librebase is not a claim of full parity. It is a Supabase-*shaped* path on a Li-native engine: SQL, REST, Auth, RLS first — Storage and Edge when contracts pass.

| | Librebase | Typical expectation of “alternative” |
|--|-----------|--------------------------------------|
| Engine | Li-native lidb path | Postgres + large JS/Go stack |
| Status | Capability matrix / contracts | Marketing checklists |
| Agents | MCP + REST | Often app-SDK first |
| Hosting | Self-host + Cloud waitlist | Managed default |

If you need every Supabase feature tomorrow, stay on Supabase. If you want a lean Postgres-compatible platform built for agents and honest health, join the waitlist and track the matrix.
