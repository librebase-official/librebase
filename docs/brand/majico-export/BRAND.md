## 5. Design principles

Design decisions must solve a specific operational problem instead of adding visual flair for no reason. Remove any element that does not directly support security, low memory usage, or data transparency. Do not include decorative patterns unless they serve as functional status indicators for the infrastructure layer. Prioritize utility in every component to ensure agents can operate without unnecessary overhead.

### 2. Accent Discipline
Apply the accent color #495d36 only where it emphasizes critical alerts or active connections within agent flows. Use this hue sparingly to maintain a professional and calm environment that does not distract from data integrity checks. Avoid using bright neon variations unless marking urgent system events requiring immediate attention by human oversight teams.

### 3. Tokens as Contract
Maintain strict consistency between design tokens in the DESIGN file and CSS variables used for rendering output. Treat every color value, spacing unit, and border radius as a binding contract that agents must respect during runtime execution. Do not hardcode styling directly into components without referencing these defined values first.

### 4. Light And Dark First Class
Build interface layouts so they function equally well under both light and dark operating system themes by default. Ensure contrast ratios meet accessibility standards regardless of ambient lighting conditions in the developer workspace. Avoid creating a master theme for only one mode and deriving another through simple color inversions without adjustment.

### 5. Whitespace And Confidence
Allow generous spacing around data elements to communicate that information is verified, secure, and not cluttered with noise. Trust your typography system enough to use large margins instead of cramming metrics into tight tables or dense lists. Use whitespace as a visual signal for safety rather than treating it as wasted screen real estate in the interface.

### 6. Authenticity Over Templates
Reject generic SaaS layouts that imply managed services while offering full self-hosting capabilities behind the scenes. Design interfaces that clearly reflect raw infrastructure status instead of polishing metrics to appear more impressive than they are. Show actual memory usage and token counts openly rather than hiding them behind vague health bars or proprietary analytics dashboards.

### 7. Agent Transmissible Brand
Export brand assets in a structured format that agents can import without manual configuration by human operators every time. Define connection parameters so any compliant agent builds automatically inherit the correct visual style upon first initialization. Avoid exporting flat image files as primary sources because dynamic components allow real-time adaptation to different deployment environments.
